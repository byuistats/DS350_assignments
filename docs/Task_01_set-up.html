Git is a program that helps you organize code and keep track of any changes you make. Git uses folders called “repositories” to organize code into different projects. GitHub is an online platform where you can store your Git repositories, and then access them from any computer. You will use Git and GitHub this semester to submit your homework, in a repository made specifically for this class.

  1. Study Chapter 8: R for Data Science—Projects

  2. Install Git on your computer. Then link the repository we created for you on GitHub to an RStudio project dedicated specifically to this class. Either read these instructions or watch this video that walks you through the process of setting everything up and ensuring RStudio is talking to GitHub. If you can’t get it to work, reach out for help! This is a critical step to being able to turn in assignments.

    Warning

    If you didn’t put your Github info on the google sheet referenced in the “pre” part of this task, and accept the two invitations, then you will need to do so ASAP. Do not simply create your own repository since we want the repository to belong to our class organization.

  3. After completing step 2 above , edit the README.md in RStudio to include a short description of yourself, and “push” the changes to the online version of your repository.

  4. To practice “pulling”:

    1. Now edit your README.md file from online instead of from within RStudio. Navigate to your repository and open the readme.md file. Below your description, add links to the repos of everyone in your group (you may need to finish this part in class, or ask them over slack).

    2. Go back to RStudio. Notice that the repo links do not appear in your README.md

    3. Using the terminal (next to the console) or Git tab in RStudio, pull the online changes you made to update the files on your hard drive.

    4. Let’s make one more change to README.md in RStudio by adding the name of your group. Then push the change to GitHub online.

You will want to get in the habit of pull, add/stage, commit, push (in that order!) at least once everyday.
