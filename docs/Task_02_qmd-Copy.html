Submission

In I-learn, submit a link to your First_Quarto_File.html published on your GitHub pages website. To find the link to this file, follow these steps:

  1. Navigate to your GitHub pages website homepage.

    • The homepage for your website can be found by going to your repository’s setting icon, and then choosing “pages” from the menu on the left. You will be brought to a page that has a button near the top labeled, “Visit site”. Click that button to go to your website’s homepage. The url, or web address, is your starting point. It will probably end in something like .pages.github.io

  2. Then tack on to the end of the url from step 1 the file path to your .html file. The path is relative to the docs/ folder.

    • For example, imagine you saved the my_task.qmd file in the w01 folder. When you render my_task.qmd, the my_task.html file should appear in the docs/w01 folder. Thus, the path to add is /w01/my_task.html.

    In summary if your home page address was https://crazy-random234.pages.github.io then url you should visit to see your file (and the url to submit) would be

    https://crazy-random234.pages.github.io/w01/my_task.html
